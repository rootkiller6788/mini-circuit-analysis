# Course Alignment — mini-two-port-network

## Nine-School Curriculum Mapping

### MIT
- **6.002 Circuits and Electronics**: Two-port parameters (Z, Y, H), Thevenin/Norton equivalents
- **6.003 Signal Processing**: Transfer functions, frequency response, filter design
- **6.012 Microelectronic Devices**: MOSFET/BJT small-signal models (hybrid-π)
- Mapping: Z/Y/H parameter basics, Miller theorem, max power transfer

### Stanford
- **EE101A Circuits**: Phasors, complex impedance, frequency-domain analysis
- **EE114 Analog IC Design**: Amplifier two-port analysis, Miller effect
- **EE214 Advanced Analog IC**: High-frequency models, Y-parameters, fT
- **EE359 Wireless Communications**: S-parameters, stability, matching networks
- Mapping: Full amplifier analysis pipeline, LNA design example

### Berkeley
- **EE16A/B Designing Information Devices**: Matrix inversion for circuit analysis
- **EE105 Microelectronic Devices**: BJT h-parameter model, CE/CB/CC configurations
- **EE140 Analog IC Design**: MOS intrinsic gain, source follower
- **EE117 EM Waves**: Transmission line ABCD, reflection coefficient
- Mapping: H-parameter BJT analysis, G-parameter FET analysis, Δ-Y transform

### Illinois
- **ECE 451 EM & RF Engineering**: Network interconnections, Bartlett's theorem
- **ECE 459 Communications**: Filter design, cascade analysis
- Mapping: Interconnection rules, Bartlett bisection, filter synthesis

### Michigan  
- **EECS 411 Microwave Circuits**: S-parameters, stability, amplifier design
- **EECS 455 Digital Communications**: System cascade analysis
- Mapping: S-parameter full suite, stability analysis, group delay

### Georgia Tech
- **ECE 6350 Microwave Engineering**: Parameter conversion (Frickey), μ-factor stability
- **ECE 6601 Communication Systems**: RF chain analysis, de-embedding
- Mapping: Full 30-method conversion, stability circles, coupled-line filters

### TU Munich
- **High-Frequency Engineering (Hochfrequenztechnik)**: Vierpoltheorie (two-port theory)
- **Communications Engineering**: Kettenschaltung (cascade), filter synthesis
- Mapping: ABCD cascade, T/π equivalent circuits, image parameters

### ETH Zurich
- **227-0427 Signal Processing**: Filter approximations
- **227-0436 Communications**: RF system design
- **227-0455 Microwave Circuit Design**: S-parameter theory, VNA calibration
- Mapping: Filter design pipeline, S-parameter analysis, de-embedding

### Tsinghua (清华)
- **电路原理 (Circuit Principles)**: Two-port network theory
- **信号与系统 (Signals & Systems)**: Fourier/Laplace analysis
- **高频电子线路 (HF Electronic Circuits)**: RF amplifier design
- Mapping: Complete two-port theory, filter design, amplifier analysis
