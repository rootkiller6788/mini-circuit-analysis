# Course Alignment - mini-network-theorem

## MIT
- **6.002 Circuits and Electronics**: Node/mesh analysis, Thevenin/Norton equivalents,
  superposition, two-port parameters
- **6.003 Signal Processing**: Complex impedance, frequency response
- **6.630 Electromagnetics**: S-parameters, transmission line matching

## Stanford
- **EE102A Signal Processing and Linear Systems I**: Linear circuit analysis,
  matrix methods for nodal/mesh
- **EE359 Wireless Communications**: S-parameters, impedance matching networks,
  maximum power transfer in RF

## Berkeley
- **EE16A/B Designing Information Devices and Systems**: Nodal analysis,
  superposition, Thevenin/Norton
- **EE105 Microelectronic Circuits**: Two-port small-signal models, H-parameters
- **EE117 Electromagnetics**: S-parameters, ABCD cascade

## Illinois (UIUC)
- **ECE 310 Digital Signal Processing**: Matrix methods for circuit analysis
- **ECE 459 Communications Systems**: Impedance matching, two-port network theory

## Michigan
- **EECS 351 Digital Signal Processing**: Linear systems, matrix solvers
- **EECS 411 Microwave Circuits**: S-parameters, matching networks, ABCD cascade

## Georgia Tech
- **ECE 4270 DSP**: Matrix-based system analysis
- **ECE 6350 EM**: Network parameter conversions (Z-Y-S-ABCD)

## TU Munich
- **Signal Processing**: Linear systems, Gaussian elimination
- **High-Frequency Engineering**: S-parameters, matching, two-port analysis

## ETH Zurich
- **227-0427 Signal Processing**: Linear algebra for circuit analysis
- **227-0436 Communications**: Two-port network theory, matching
- **227-0455 Electromagnetics**: S-parameters, transmission line theory

## Tsinghua University
- **Signal and Systems**: Network theorems, nodal/mesh analysis
- **Communications Principles**: Two-port parameters, impedance matching
- **Electromagnetic Fields**: S-parameters, transmission parameters
